# Namra Shah

Backend-leaning software engineer based in Vadodara, India. Currently building the backend of a task management platform at **CognitionIES** with Node.js, TypeScript, PostgreSQL, RabbitMQ, and AWS.

Most of my work is on the backend: APIs, query performance, real-time sync, auth, and deploys. I also ship full-stack when a project needs it. Outside of work I build projects to understand systems from the inside out.

---

### What I'm working on

- **[Chess Engine](https://github.com/Shah-Namra/Chess-Engine)** — A chess engine in C++17, built from scratch. Bitboards, iterative deepening alpha-beta, a Zobrist-hashed transposition table, and move ordering. Roughly 80% search-node reduction across iterations, benchmarked on 100 Lichess mate-in-3 puzzles.
- **[CinemaRanked](https://github.com/Shah-Namra/CinemaRanked)** — Elo-based head-to-head movie ranking. Dynamic K-factors, weighted pairing, and atomic vote transactions with `SELECT FOR UPDATE` in PostgreSQL.
- **[Queued](https://github.com/Shah-Namra/Queued)** — A real-time collaborative music playlist app. Socket.IO for live sync, Redis caching, k6 load-tested locally.

More detail and writeups on my site: **[shahnamra.com](https://shahnamra.com)**
